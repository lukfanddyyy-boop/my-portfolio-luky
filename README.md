## 🎯 Customization Guide

### Mengganti Foto
1. Ganti placeholder di `.image-placeholder` dengan `<img>` tag
2. Letakkan foto di folder `assets/images/`
3. Gunakan format: `<img src="assets/images/photo.jpg" alt="Luky Irfandi">`

### Mengubah Warna
- Edit nilai warna di `css/style.css`
- Main colors:
  - Background: `#0a0a0a` (dark black)
  - Text: `#ffffff` (white)
  - Borders: `#2a2a2a` (light gray)

### Menambah Social Media
Edit di navbar dan contact section:
```html
<a href="https://instagram.com/yourprofile" target="_blank">
    <i class="fab fa-instagram"></i>
</a>
```
